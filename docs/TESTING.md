# Testing

Run the complete project test/build suite with JDK 25:

```bash
./gradlew clean test build
```

The API tests cover frame bounds, identifier validation, defensive copies, frame ordering, duration constraints, per-animation damage overrides, camera-cone settings, and plugin-defined ModelPose bounds/defaults. Paper tests cover fractional-time path matching, actor-local/world coordinate conversion, and rejecting movement away from the authored path. Fabric tests cover smooth fractional positions, zero-velocity scene boundaries, eased pose entry/exit, keyframe animation crossfades, immediate camera-bound reversal, F5 front-camera mirroring, camera mode propagation, acceptance/interpolation of namespaced custom pose packets, and visual-only early-stop fade behavior. The Paper and Fabric modules compile against Minecraft/Paper 26.2 and run their available unit tests. The CI workflow builds all modules and verifies the produced plugin and mod artifacts.

A build does not replace an in-game integration test. Before production deployment, test at least: Paper 26.2 with Fabric Loader 0.19.5+ and Fabric API 0.161.0+26.2; one actor and multiple viewers; a viewer entering range mid-scene; register a brand-new namespaced animation in a separate Paper plugin and verify it plays on the same protocol-v3 client without rebuilding the mod; malformed/out-of-bounds pose packet rejection; actor-local forward/right path alignment at several starting yaw angles; actor-facing travel direction; no server teleport packets during normal scene progression; local WASD/jump/sprint/shift suppression and restoration on stop; `FREE_LOOK` preserving mouse aim; `LOCKED` eased camera entry and authored yaw/pitch tracking; `LIMITED` hard stop at both yaw/pitch boundaries, immediate response when reversing, and inability to turn behind the actor; first-person, rear-F5 and front-F5 views at nonzero yaw/pitch; local head/camera aim agreement; viewers retaining independent cameras; optional FOV/roll/shake clamps and camera partial-tick alignment; per-animation policy changes exactly at their keyframes; `CANCEL_SCENE` stopping before a real hurt reaction; `IGNORE_DAMAGE` preserving health and suppressing hurt/knockback while leaving the scene active; hits already cancelled by other plugins; the `thunderclap-flash` charge, 24-block/six-tick dash and finish timing at several actor yaw angles and packet phases; its uninterrupted run through the integer and fractional points at every dash segment; wall, corner, unloaded-chunk and world-border dash cancellation without passing through obstacles; held sword/armor tracking during charge and slash; pose continuity on normal completion and early STOP; render continuity at 30/60/144 FPS; external teleport cancellation; disconnect, world transfer, reload, and plugin disable; no-client and mismatched-protocol clients; and a representative animation/camera modpack. CI only verifies compilation and packaging and does not claim these live visual checks have passed.
