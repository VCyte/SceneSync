# Testing

Run the complete project test/build suite with JDK 25:

```bash
./gradlew clean test build
```

The API tests cover frame bounds, identifier validation, defensive copies, frame ordering, duration constraints, per-animation damage overrides, camera-cone settings, and plugin-defined ModelPose bounds/defaults. Paper tests cover fractional-time path matching, actor-local/world coordinate conversion, rejecting movement away from the authored path, stationary safe-prefix clipping, and collision-brace/recovery timeline construction. Fabric tests cover NTP-style offset estimation and minimum-RTT sample selection, origin-pitch preservation, smooth fractional positions, eased root-facing entry and corner turns, zero-velocity scene boundaries, eased pose entry/exit, keyframe animation crossfades, combined head/camera overlay limits, immediate camera-bound reversal, F5 front-camera mirroring, camera mode propagation, acceptance/interpolation of namespaced custom pose packets, and root/pose handoff after early STOP and natural completion. The Paper and Fabric modules compile against Minecraft/Paper 26.2 and run their available unit tests. The CI workflow builds all modules and verifies the produced plugin and mod artifacts.

A build does not replace an in-game integration test. Before production deployment, test at least: Paper 26.2 with Fabric Loader 0.19.5+ and Fabric API 0.161.0+26.2; one actor and multiple viewers; measure command-to-first-frame delay and verify the 100 ms shared lead; compare five-probe offset estimates across low/high RTT and asymmetric routes; a viewer entering range mid-scene and receiving the exact original world origin; register a brand-new namespaced animation in a separate Paper plugin and verify it plays on the same protocol-v3 client without rebuilding the mod; malformed/out-of-bounds pose packet rejection; actor starting pitches from -70° to +70° with neutral pitch keyframes preserving their view and head direction; actor-local forward/right path alignment at several starting yaw angles; smooth root turns at direction changes; no server teleport packets during normal scene progression; local WASD/jump/sprint/shift suppression and restoration on stop; `FREE_LOOK` preserving mouse aim; `LOCKED` eased camera entry and authored yaw/pitch tracking; `LIMITED` hard stop at both yaw/pitch boundaries, immediate response when reversing, and inability to turn behind the actor; first-person, rear-F5 and front-F5 views at nonzero yaw/pitch; extreme head pitch/yaw/roll keyframes combined with camera aim without neck inversion; viewers retaining independent cameras; optional FOV/roll/shake clamps; per-animation policy changes exactly at their keyframes; `CANCEL_SCENE` and `IGNORE_DAMAGE` behavior; the `thunderclap-flash` 24-block/six-tick dash under multiple client latencies and server TPS; players at identical origins receiving identical accepted paths; static wall/corner/unloaded-chunk/world-border obstructions producing a preplanned stationary brace without entering then rolling back; a block appearing dynamically during playback; armor/held-item tracking; pose and root continuity on normal completion and early STOP; render continuity at 30/60/144 FPS; external teleport cancellation; disconnect, world transfer, reload, and plugin disable; no-client and mismatched-protocol clients; and representative modpacks. CI only verifies compilation and packaging and does not claim these live visual checks have passed.
